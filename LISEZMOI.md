# Fountain Technique — Installer l’app sur téléphone

## 1. Mettre l’app en ligne (2 minutes)

1. Télécharge `fountain-app.zip`
2. Va sur **https://tiiny.host** (gratuit, depuis le téléphone)
3. Envoie le ZIP
4. Tu reçois un lien (ex. `https://xxx.tiiny.site`)
5. Ouvre ce lien dans **Safari** (iPhone) ou **Chrome** (Android)

## 2. Installer comme une vraie application

### iPhone (Safari)
1. Ouvre le lien dans **Safari** (pas Chrome)
2. Appuie sur **Partager** (carré avec flèche)
3. **Sur l’écran d’accueil**
4. Appuie sur **Ajouter**
5. L’icône Fountain apparaît comme une app

### Android (Chrome)
1. Ouvre le lien dans **Chrome**
2. Menu **⋮** → **Installer l’application**  
   (ou une bannière « Installer Fountain » dans l’app)
3. Valide
4. L’icône apparaît sur l’écran d’accueil

## 3. Notifications

À la première connexion, le téléphone demande l’autorisation.

- **Acceptées** → alertes système pour nouveaux messages / tickets
- **Refusées** → les alertes restent dans l’app (toasts)

Les notifications marchent surtout quand l’app est ouverte ou récente.
Les push en arrière-plan 24h/24 demandent un serveur dédié (possible plus tard).
